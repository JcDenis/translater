main is read by Dotclear on the administration side, public on the public side. Any other group must be loaded by the module itself.
Greyed lines
The string is already translated by Dotclear and the setting "Translate only unknown strings" is on: it cannot be edited.
Existing
Translations of the same string found in other modules. The first icon copies one in the field.
Last empty line
Adds a string of your own. Lines starting with + are plural forms.
