Translations
Click a language to edit it. Select languages, then choose an action: backup, delete or export (a zip package).
Backups
Restore or delete the selected backups. Several backups of the same language are restored from the oldest to the newest.
Add language
Creates a new translation, optionally copied from an existing language of the module.
Import
Imports a zip package of languages, typically one exported by Translater. Existing languages are replaced only if the setting allows it.
